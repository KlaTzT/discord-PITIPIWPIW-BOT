# Pon Attendance Bot

บอท Discord เช็คเวลาซ้อม + ระบบแจ้งลา/ใบเตือน/ใบแดง เก็บข้อมูลหลักเป็นไฟล์ .json บนเครื่อง แล้วเขียนผลสรุปขึ้น Google Sheets ให้ดู

## สิ่งที่ต้องเตรียมก่อน

### 1. บอท Discord
1. สร้างแอปที่ https://discord.com/developers/applications แล้วสร้าง Bot
2. เปิด Privileged Gateway Intents: **SERVER MEMBERS INTENT** และ **PRESENCE INTENT ไม่จำเป็น** (แค่ Members กับ ปกติ Voice States เปิดอยู่แล้วโดยดีฟอลต์)
3. เชิญบอทเข้าเซิร์ฟเวอร์ด้วยสิทธิ์: View Channels, Send Messages, ใช้ scope `bot` + `applications.commands`
4. คัดลอก Bot Token, Application (Client) ID, และ Guild (Server) ID มาใส่ในไฟล์ `.env`

### 2. Google Sheets
1. สร้างโปรเจกต์ที่ Google Cloud Console แล้วเปิดใช้ **Google Sheets API**
2. สร้าง Service Account แล้วดาวน์โหลดคีย์เป็นไฟล์ JSON เก็บไว้ที่ `credentials/service-account.json`
3. เปิด Google Sheet ที่จะใช้บันทึกผล แล้ว **Share ให้กับอีเมลของ Service Account** (สิทธิ์ Editor) — อีเมลนี้ดูได้ในไฟล์ JSON ที่โหลดมา (field `client_email`)
4. คัดลอก Sheet ID (ส่วนที่อยู่ใน URL ระหว่าง `/d/` กับ `/edit`) ใส่ `.env`

### 3. ตั้งค่า .env

สร้างไฟล์ `.env` ที่ root ของโปรเจกต์ (ห้าม commit ขึ้น git เด็ดขาด เพราะมี token จริงอยู่ข้างใน) ใส่ค่าดังนี้:
```
DISCORD_TOKEN=
CLIENT_ID=
GUILD_ID=
LEAVE_CHANNEL_ID=
GOOGLE_SHEET_ID=
GOOGLE_SERVICE_ACCOUNT_FILE=./credentials/service-account.json
```
(LEAVE_CHANNEL_ID คือห้องแจ้งลาที่บอทจะไปโพสต์ปุ่มค้างไว้)

### 4. เตรียมแท็บใน Google Sheet ให้ตรงชื่อ

บอทจะสร้างแท็บให้อัตโนมัติถ้ายังไม่มี แต่ถ้าคุณสร้างเองไว้ก่อนแล้ว ต้องตั้งชื่อแท็บให้ตรงเป๊ะ:

| แท็บ | คอลัมน์ |
|---|---|
| `วอร์ปาร์ตี้หลัก` | วันวอร์, ตัวละคร, Discord, เข้า, ออก, รวมนาที, กี่ช่วง |
| `วอร์ปาร์ตี้รอง` | เหมือนกัน |
| `กิจกรรมกิลด์` | เหมือนกัน (วันพฤหัส 21:00-21:45 ห้องพูดคุยหลัก) |
| `ตีบอสกิลด์` | เหมือนกัน (วันอาทิตย์ 18:00-20:00 ห้องพูดคุยหลัก) |
| `วอร์วันอาทิตย์` | เหมือนกัน (วันอาทิตย์ 20:01-22:00 ห้องพูดคุยประสาท) |
| `แจ้งลา` | ตัวละคร, ลาวันวอร์วันที่, แจ้งเมื่อ |
| `ใบเตือน` | Discord, ตัวละคร, เหตุ, ได้รับใบ |
| `ผูกID` | Discord, ตัวละคร |
| `สรุป` | Discord, ชื่อตัวละคร, เดือน, มาวอร์ (รอบ), ขาด (รอบ), ลากิจ (ครั้ง), ใบเตือน (ใบ), เวลาห้องเสียงรวม (นาที), นับขาดรวม, สถานะ |

> แท็บ `เช็คห้องพูดคุย` **เลิกใช้แล้ว** (แยกเป็น `กิจกรรมกิลด์`/`ตีบอสกิลด์`/`วอร์วันอาทิตย์` แทนแล้ว) ลบทิ้งเองได้จากชีตจริงถ้าต้องการ บอทจะไม่เขียนอะไรลงไปอีก

## ตารางเช็คทั้งหมด (แต่ละอันเป็นอิสระต่อกัน ไม่มีการรวม/พักผลข้ามช่วงเวลาแล้ว)

| วัน | เวลา | ห้อง | เขียนแท็บ | นับเป็น "วอร์" ในสรุปไหม |
|---|---|---|---|---|
| อังคาร/พฤหัส | 20:00-22:25 | สนามตี้หลัก+รอง | `วอร์ปาร์ตี้หลัก`/`วอร์ปาร์ตี้รอง` | ✅ นับ |
| พฤหัส | 21:00-21:45 | พูดคุยหลัก | `กิจกรรมกิลด์` | ❌ ไม่นับ |
| อาทิตย์ | 18:00-20:00 | พูดคุยหลัก | `ตีบอสกิลด์` | ❌ ไม่นับ |
| อาทิตย์ | 20:01-22:00 | พูดคุยประสาท | `วอร์วันอาทิตย์` | ✅ นับ |

เกณฑ์ผ่าน (ไม่ไฮไลท์เหลือง): สนามตี้หลัก/รอง ≥30 นาที, กิจกรรมกิลด์ ≥40 นาที (จาก 45 หักผ่อนผัน 5), ตีบอสกิลด์ ≥115 นาที (จาก 120 หักผ่อนผัน 5), วอร์วันอาทิตย์ ≥114 นาที (จาก 119 หักผ่อนผัน 5)

## ระบบเช็คมา/ลา/ขาด + DM สรุป

หลังจบแต่ละรอบเช็คในตารางด้านบน บอทจะเทียบรายชื่อคนที่ผูกไว้ทั้งหมดกับคนที่เข้าห้องจริง แบ่งเป็น 4 กลุ่ม:
- **มา** (เข้าครบเกณฑ์) **ลา** (มีใบลาอนุมัติของวันนั้นอยู่แล้ว) **มาไม่ครบเวลา** (เข้าห้องแต่เวลาไม่ถึงเกณฑ์ — โชว์จำนวนนาทีที่เข้าจริงด้วย) **ขาด ไม่มาเลย** (ไม่เข้าห้องเลยสักวินาที และไม่ได้ลา)

แล้ว:
- ส่ง DM สรุปทั้ง 4 กลุ่มไปหาแอดมิน (ตั้งค่า user ID ได้ที่ `ATTENDANCE_REPORT_USER_ID` ใน `src/config.js`)
- อัปเดตแท็บ `สรุป` ให้คนนั้น (1 คน 1 แถวต่อเดือน อัปเดตทับไปเรื่อยๆ ไม่สร้างแถวซ้ำ)
- ถ้า "มาไม่ครบเวลา" หรือ "ขาด ไม่มาเลย" (รวมทุกประเภทการเช็ค) ครบ 3 ครั้งในเดือนเดียวกัน จะได้ **ใบเตือนอัตโนมัติ** (ปรับจำนวนได้ที่ `ABSENCE_WARNING_THRESHOLD`) ใช้ก้อนใบเตือน/ใบแดงเดียวกับระบบลากิจ (สะสมครบ 2 ใบ = ใบแดง)
- คอลัมน์ "มาวอร์"/"ขาด (รอบ)" นับเฉพาะรอบที่ทำเครื่องหมาย ✅ ในตารางข้างบน (วอร์อังคาร/พฤหัส + วอร์วันอาทิตย์) กิจกรรมกิลด์/ตีบอสกิลด์ไม่กระทบ 2 คอลัมน์นี้ แต่ยังนับรวมใน "นับขาดรวม" และเกณฑ์ใบเตือนอัตโนมัติเหมือนกัน ทั้งหมดนับรายเดือน ไม่สะสมข้ามเดือน

## ทดสอบระบบเช็คห้อง/เขียนชีต/DM โดยไม่ต้องรอตารางจริง

ระบบเช็คจะเขียนชีต+ส่ง DM ตอนจบช่วงเวลาตามตารางจริงเท่านั้น (เช่นวอร์อังคารจะทำตอน 22:25) ถ้าอยากทดสอบทันทีโดยไม่ต้องรอ ใช้ 2 คำสั่งนี้ได้ (จำกัดเฉพาะคนมีสิทธิ์ Manage Server ในดิส กันคนอื่นกดเล่นแล้วรอบจริงพัง):

```
/ทดสอบเริ่ม วัน:วันอังคาร (วอร์)   -> เริ่มนับเวลาทันที (คนที่อยู่ในห้องตอนนั้นจะถูกนับ)
/ทดสอบจบ วัน:วันอังคาร (วอร์)     -> ปิดรอบ คำนวณผล เขียนชีต + ส่ง DM สรุปทันที
```

ตัวเลือก `วัน` มี 3 แบบตามวันจริง: วันอังคาร (วอร์อย่างเดียว), วันพฤหัสบดี (วอร์ + กิจกรรมกิลด์ ทดสอบพร้อมกันทั้ง 2 รอบ), วันอาทิตย์ (ตีบอสกิลด์ + วอร์วันอาทิตย์ ทดสอบพร้อมกันทั้ง 2 รอบ) — ห้ามใช้คำสั่งนี้ระหว่างรอบจริงกำลังทำงานอยู่ (บอทจะเตือนและปฏิเสธถ้าตรวจพบว่ารอบนั้น active อยู่แล้ว)

## ติดตั้งและรัน

```
npm install
npm run register-commands   # ลงทะเบียน slash command กับ guild (ทำครั้งเดียว หรือทุกครั้งที่แก้คำสั่ง)
npm start                   # รันบอท
```

รันแบบค้างไว้ตลอดบน VPS ด้วย pm2:
```
npm install -g pm2
pm2 start ecosystem.config.js
pm2 save
pm2 startup   # ทำตามคำสั่งที่ pm2 แนะนำ เพื่อให้บอทรันอัตโนมัติเวลาเครื่อง reboot
```

## โครงสร้างข้อมูล

- `data/bindings.json` — ผูกชื่อเกม ↔ Discord ID (1:1)
- `data/leaves.json` — ประวัติการลา/ใบเตือน/ใบแดง รายเดือน (นับตามเดือนของ "วันวอร์ที่เลือกจะลา")
- `data/liveSessions.json` — สถานะการนับเวลาที่กำลังทำงานอยู่ (กันข้อมูลหายถ้าบอทรีสตาร์ทกลางช่วงที่กำลังเช็ค)
- `data/leavePanel.json` — เก็บ message ID ของปุ่มลากิจที่โพสต์ค้างไว้ กันโพสต์ซ้ำเวลาบอทรีสตาร์ท
- `data/attendance.json` — สถิติมา/ขาด/เวลารวมรายเดือนของแต่ละคน (ใช้คำนวณแท็บ `สรุป` และเช็คเกณฑ์ใบเตือนอัตโนมัติจากการขาด)

ไฟล์เหล่านี้คือฐานข้อมูลจริง ควร **backup เป็นระยะ** (เช่น copy ไปโฟลเดอร์อื่นทุกวัน) เพราะอยู่บนเครื่องเดียว ไม่มี replication

## การแจ้งลา (ยืนยันกับผู้ใช้แล้ว)

บอทจะโพสต์ข้อความปุ่ม "แจ้งลากิจ" ค้างไว้ในห้องแจ้งลาให้เอง (ไม่ใช้คำสั่งพิมพ์ /ลากิจ อีกต่อไป — ถูกแทนที่ด้วยปุ่มนี้เพราะกันพิมพ์ชื่อผิดและมี UX ดีกว่า):
1. กดปุ่ม → บอทรู้ชื่อจากที่ผูกไว้อัตโนมัติ ไม่ต้องพิมพ์ชื่อเอง
2. เลือกวันวอร์ที่จะลาจากดรอปดาวน์ (แสดงเสมอ 3 ตัวเลือก เรียงอังคาร → พฤหัสบดี → อาทิตย์ ตัวละวันที่ใกล้ที่สุด)
3. บอทประกาศในห้องทันที: ชื่อ, ลาไปแล้วกี่ครั้ง/เหลือกี่ครั้งในเดือนนั้น, แจ้งก่อนหรือหลัง 15:00

กติกา:
- ลาได้ไม่เกิน 3 ครั้งต่อเดือน (**นับตามเดือนของวันวอร์ที่เลือกจะลา** ไม่ใช่เดือนที่กดปุ่ม) — กดครั้งที่ 4 ปุ่มจะบล็อกทันที ขึ้นข้อความว่าลาครบโควตาแล้ว ต้องติดต่อแอดมินเอง
- ก่อน/หลัง 15:00 **เทียบกับ 15:00 ของวันวอร์ที่เลือกจะลา** ไม่ใช่เวลาที่กดปุ่ม (เช่นกดวันจันทร์ขอลาวันพฤหัส ถือว่าแจ้งก่อน 15:00 เสมอเพราะกดล่วงหน้า, แต่ถ้ากดวันพฤหัสเอง หลัง 15:00 น. ของวันนั้น ถือว่าแจ้งช้า)
- แจ้งช้า (หลัง 15:00 ของวันวอร์นั้น) → ได้ใบเตือน 1 ใบ, สะสมครบ 2 ใบ → ใบแดง
- ทุกครั้งที่มีใบเตือน/ใบแดงเกิดขึ้น จะถูกบันทึกลงแท็บ `ใบเตือน` ในชีตด้วย

## ข้อสมมติที่ยังไม่ได้ยืนยัน (ปรับได้ที่ `src/config.js` หรือ `src/features/leavePanel.js`)

- แต่ละสนามซ้อม (หลัก/รอง) นับเวลาแยกกันคนละแท็บ ถ้าสลับสนามระหว่างซ้อมจะถือว่าจบช่วงในสนามเดิมแล้วเริ่มช่วงใหม่ในอีกสนาม (นับเป็นคนละ "ช่วง" กันในคอลัมน์กี่ช่วง)
- คนที่ไม่เคยเข้าห้องเลยในช่วงที่เช็ค จะไม่มีแถวในแท็บนั้นๆ (เฉพาะคนที่เข้าอย่างน้อยครั้งเดียวถึงจะถูกบันทึกที่นั่น) แต่จะยังโผล่ในแท็บ `สรุป` และ DM ฝั่ง "ขาด ไม่มาเลย" เสมอ เพราะอิงจากรายชื่อที่ผูกไว้ทั้งหมด
- วันที่ทุกจุดในชีต (รวมคอลัมน์ "แจ้งเมื่อ"/ประวัติการลา) เป็นปี ค.ศ. รูปแบบ วัน/เดือน/ปี ทั้งหมดแล้ว
- ขาดครบ 3 ครั้ง/เดือน (นับรวมทุกรอบเช็ค ทั้งวอร์และกิจกรรมกิลด์/ตีบอสกิลด์) ถึงจะโดนใบเตือนอัตโนมัติ 1 ใบ ("มาไม่ครบเวลา" ก็นับเป็นขาดด้วย ไม่ใช่แค่ไม่มาเลย) ปรับเกณฑ์ได้ที่ `ABSENCE_WARNING_THRESHOLD` ใน config.js
- DM สรุปมา/ลา/ขาด ส่งหา user ID เดียว (`ATTENDANCE_REPORT_USER_ID`) ยังไม่รองรับส่งหลายคน ถ้าต้องการเพิ่มบอกได้
